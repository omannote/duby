# دوبي — نظام طلبات الغسيل عبر QR

نظام إدارة طلبات **دوبي للغسيل السريع والجاف**. كل عميل له رمز QR دائم في شقته،
ومسحه يُنشئ طلبًا جديدًا. الاستلام والتسليم يتمّان بمسح رمز العميل مع صورة في
الموقع.

**الحالة**: المراحل صفر إلى سبع مكتملة. المخطط والواجهتان ووظائف Edge
والتقارير وسكربتات الترحيل جاهزة ومُختبَرة. ما يبقى بشريًا (أجهزة حقيقية،
مفاتيح المزوّدين، التدريب والإطلاق) في
[قوائم المرحلة السابعة](docs/plan/phase-7-launch.md).

## البنية

```
apps/staff/        لوحة الموظفين — React + Vite (PWA لاحقًا)
apps/customer/     صفحة العميل العامة — حزمة منفصلة خفيفة
packages/shared/   الأنواع والمخططات ورموز الأخطاء وآلة الحالات
supabase/          الهجرات ووظائف Edge والبيانات البذرية
tests/db/          pgTAP — القيود والسياسات
tests/e2e/         Playwright — Chromium و WebKit
scripts/           فحص الترويسات، توليد الأنواع، تشغيل اختبارات القاعدة
```

## التشغيل محليًا

المتطلبات: Node ‏20+ · pnpm ‏10 · Docker يعمل · [Supabase CLI](https://supabase.com/docs/guides/local-development).

```bash
pnpm install
supabase start          # يرفع القاعدة والمصادقة والتخزين ووظائف Edge
```

انسخ `ANON_KEY` من مخرجات الأمر إلى ملف البيئة، ثم شغّل الواجهتين:

```bash
cp .env.example .env.local
# ضع قيمة ANON_KEY في VITE_SUPABASE_ANON_KEY
pnpm dev
```

| العنوان                | ما هو                               |
| ---------------------- | ----------------------------------- |
| http://127.0.0.1:5173  | لوحة الموظفين                       |
| http://127.0.0.1:5174  | صفحة العميل                         |
| http://127.0.0.1:54323 | Supabase Studio — الجداول والبيانات |
| http://127.0.0.1:54324 | Mailpit — البريد الصادر محليًا      |

### حسابات التطوير

البذرة تُنشئ أربعة حسابات، كلمة المرور لها جميعًا `devpass123`:

| البريد                | الدور       | ما يضيفه عمّا قبله                         |
| --------------------- | ----------- | ------------------------------------------ |
| `courier@duby.local`  | مندوب       | الطلبات الميدانية، صندوقه، إيداعه          |
| `operator@duby.local` | مشغّل       | اعتماد التسويات، أعمار الفواتير، قمع المسح |
| `manager@duby.local`  | مشرف        | أداء المندوبين، المطابقة البنكية           |
| `admin@duby.local`    | مدير النظام | الصحة التشغيلية وبوابة جاهزية الإطلاق      |

تُنشأ فقط حين تكون القاعدة فارغة تمامًا، ولا تعمل إلا مع `supabase db reset`
محليًا. جرّب الأدوار بالتبديل بينها: الشاشة نفسها تعرض أقلّ أو أكثر بحسب الدور،
وهذا ما تفرضه سياسات RLS لا الواجهة.

### تجربة رحلة العميل

رمز QR لكل عميل في `customer_qr_tokens`:

```bash
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" \
  -c "select token from customer_qr_tokens limit 1"
```

ثم افتح `http://127.0.0.1:5174/?t=<الرمز>`.

خطوة رمز التحقق تحتاج جسر واتساب؛ بلا مفاتيحه يعمل المزيّف ويطبع الرمز في
سجلات الوظيفة — راجع [`docs/plan/08-integrations.md`](docs/plan/08-integrations.md).

التفاصيل والقواعد في [`CONTRIBUTING.md`](CONTRIBUTING.md).
